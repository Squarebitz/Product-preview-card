# Product Preview Card

This project is my solution to the Frontend Mentor challenge: a product preview card component built with HTML and CSS. It was one of the first times I really focused on matching a design closely, so I spent a lot of time refining layout, spacing, colors, and typography to make it feel as close as possible to the original mockup.

## Overview

The goal was to create a responsive product card that displays a perfume image, product title, description, price, and a call-to-action button. The design had a clean luxury style, with a soft beige background, a split card layout on desktop, and a stacked mobile version.

## The challenges I faced

This project taught me a lot as a beginner, and it pushed me to pay attention to small design details.

- Matching the layout closely to the reference design
  - Getting the image and text sections aligned perfectly took a lot of trial and error.
  - I had to adjust widths, padding, and card proportions until the layout felt balanced.

- Understanding responsive design
  - The desktop design is a horizontal split layout, while the mobile version stacks everything vertically.
  - I learned how media queries help transition the card smoothly between screen sizes.

- Styling the typography to feel premium
  - The serif headline and elegant sans-serif body text needed the right font pair and spacing.
  - Letter spacing, font-weight, and line-height had to be adjusted carefully to make the text look close to the mockup.

- Getting colors and spacing right
  - The color palette needed to match the product card exactly enough to feel consistent with the design.
  - I also learned how subtle spacing changes can make a big difference in the overall look.

- Button and hover styling
  - The CTA button was one of the most important elements because it stands out visually.
  - I spent time refining the button size, radius, color, and hover effect so it looked polished and intentional.

- Working with image backgrounds
  - Since the design uses different product images for mobile and desktop, I had to manage background-image changes responsively.
  - This helped me learn how backgrounds can be handled cleanly in CSS.

## What I learned

This project helped me improve my understanding of:

- CSS layout techniques such as flexbox
- Responsive web design using media queries
- Typography and spacing for visual balance
- Building a clean, polished UI from a design reference
- The importance of small details in front-end development

## Outcome

Even though there were many challenges, I was able to get the design very close to the original reference and improve my confidence in building styled UI components. This project was a great learning step in my frontend journey.
